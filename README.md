# channel-memory-digest

Feed this repo to your AI agent (Claude Code / Codex / Kimi / etc.) — e.g. copy it into your agent's skills directory or paste the SKILL.md — and it can run a rolling cross-channel memory digest for a small team's Discord server: every 6 hours it reads each active channel, condenses what happened, and keeps a 7-day rolling digest plus a permanent archive.

**All Discord channel IDs, the user ID, and channel names in this repo are placeholders** (e.g. `123456789012345678`, `#project-alpha`). Replace them with your own server's real values before use. The workflow, schedule, file layout, and cron setup are the real, battle-tested parts.

See `SKILL.md` for the full method.
